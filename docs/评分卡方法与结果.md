# 四字段评分卡方法与结果

当前整理日期：2026-11-04；历史源实验：20261102-185727-610962。公开整理与复现不改变研究独立性。

## 方法

FICO按训练期10分位预分箱，按样本占比5%及两类各20笔最低计数确定性并箱；类别按占比1%和两类20笔合并，NI和原生缺失保护。参数来自已固定研究方案，不按评价表现调箱，不强制单调。

仅训练样本计算WOE=ln(P_good/P_bad)，占用箱使用0.5平滑；未占用预留箱WOE=0。四列WOE进入固定L2逻辑回归，C=1；没有重采样、校准或按评价结果筛特征。

B=PDO/ln(2)，A=600−B×ln(20)，Score=A−B×eta；eta为坏样本log-odds。PDO=50，四变量分值加总还原完整精度总分。600分对应模型隐含好坏比20:1，不是经验证的真实坏账概率。

训练窗口、同分排序、80%主情景和60/70/90%辅助比例沿用基线。每年2,000次配对贷款重采样、共用抽样权重、重新等量筛选；区间不包括训练/WOE不确定性和开发选择偏差。

## 同卡稳定性

固定W1训练的分箱、WOE、系数与训练分数切点，对2014/2015/2016同一尺度计算PSI。2014为已查看参照，评分PSI到2015/2016分别为0.001089/0.004745。该结果只描述分布变化；固定卡每期仍重新选择80%保留，不是固定分数阈值迁移，也不证明稳定上线。

## 复现与限制

[公开运行入口](../scorecard_v1/README.md)从公开CSV及已审计基线运行；[导出清单](../results/scorecard/publication_manifest.json)记录公开聚合文件与历史manifest核对关系。原始CSV、逐笔贷款、模型和本地历史中间输入不随仓库提供。

所有年份已查看，数据只覆盖已放款终态贷款，缺历史标签可用日、完整观察快照与借款人键。评分卡解释性不能弥补终态选择、开发复用和真实成本缺失；正式独立验证与经济收益仍未完成。
